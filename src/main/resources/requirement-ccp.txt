[DATA MODELS]: (Use Hibernate)

Please ensure the solution follows all modern Hibernate best practices:
1. Make the child side   the owning side using @ManyToOne and @JoinColumn.
2. Use the `mappedBy` attribute on the parent side (@OneToMany) to prevent an extra join table.
3. Explicitly set `fetch = FetchType.LAZY` on the @ManyToOne side to avoid performance traps.
4. Include synchronization/helper methods in the parent class to keep both sides of the collection in sync.
5. Implement proper `equals()` and `hashCode()` using only the business key or UUID (not the database ID).
